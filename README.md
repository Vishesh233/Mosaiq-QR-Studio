# QR Code Studio v2

A modern desktop application for generating and scanning QR codes with a clean interface, multiple themes, and fast performance.

## Features

### QR Code Generator
- Generate QR codes from text or URLs
- Customize QR colors
- Add logo to QR code
- Live QR preview
- Save generated QR codes as images

### QR Code Scanner
- Scan QR codes from image files
- Detect URLs and plain text
- Clickable URL support
- Copy decoded content to clipboard
- Clear scan results instantly

### User Interface
- Modern CustomTkinter interface
- Multiple built-in themes
  - Midnight
  - Carbon
  - Deep Navy
  - AMOLED
- Responsive layout
- Clean and user-friendly design

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/QR-Code-Studio-v2.git
```

### Open Project

```bash
cd QR-Code-Studio-v2
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python main.py
```
